Applications

What shows up in the rail on the left. Drag to reorder.

Add an app

It appears in the rail straight away. You can reorder or remove it any time.
A page on the web
Anything with an address. Best for pages that do not need a login — a signed-in session cannot travel into an embedded page, so those show up logged out.
Something running on this Mac
A local dashboard on a port. CCC handles the plumbing so it renders inside the app.
Start an empty app
A blank page you or an agent can build into whatever you need.
Apps live in ~/.claude/command-center/apps/, outside the CCC repo, so updating CCC never touches them. Removing an app moves its folder to apps/.removed/ rather than deleting it.
