- Worker restarts no longer abort live Codex turns. Every automatic and API restart path (the `run.sh` stale-code roll, the maintenance roll, `/api/restart/worker` and `/api/restart/all`) now refuses while a native Codex turn runs or its state cannot be read. Each path freezes new Codex turns atomically with the live-turn count, then checks again just before stopping the worker. Pass `{"allow_codex_interrupt": true}` in the request body to restart anyway. A worker started before this change cannot report its turns, so its first restart needs that override.
