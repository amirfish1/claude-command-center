- **Browser tab in the right rail.** Previews the local dev server a session is serving, right beside the session. CCC detects it from ports listening in the session's process tree or directory and from `localhost` URLs in the transcript; a server that starts while you watch opens automatically (toggle with Auto-open). Type any URL or a bare port (`3000`) to load it. Pages that refuse to be embedded (`X-Frame-Options`, CSP `frame-ancestors`) load through a 127.0.0.1-only proxy that keeps hot reload working.
