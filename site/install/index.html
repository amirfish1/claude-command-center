Install

One line. Five minutes.
Free model included.

Works on macOS and Linux. No account, no card. The installer puts CCC on your machine, then a short tour in your browser sets up everything else, one click at a time.

curl -fsSL https://raw.githubusercontent.com/amirfish1/claude-command-center/main/scripts/install.sh | CCC_FROM=landing-hero bash

macOS and Linux. On Windows, use the PowerShell line further down.

Never used a terminal? This is all of it.

Three small steps.

  1. Open Terminal

    On a Mac: press ⌘ Cmd + Space, type Terminal, press Enter. On Linux, open whatever terminal app you have.

  2. Paste the line, press Enter

    CCC downloads itself into ~/.ccc and asks you one yes/no question: whether to keep running in the background. Say yes.

  3. Your browser opens the setup tour

    A friendly full-screen tour installs the rest (Node, Claude Code, a free model). Every step asks your OK first. Nothing happens silently.

What the tour installs for you

Everything a coding agent needs.

Node.js

The runtime the agent tools need. CCC downloads the official LTS release into its own folder. Your system stays untouched, no admin password.

Claude Code

The agent that does the work. Installed by the official installer, launched for you. You can also drive Codex, Cursor, and Antigravity from the same board.

A free model

CCC sets up a local free-model router so your first tasks cost $0. The keyless option logs prompts for training; the tour tells you and asks before turning it on.

Your first task

A small real change in a playground project, run on the free model. When it finishes you see exactly what it would have cost at API prices. Spoiler: you paid $0.

Other ways to install

Pick what fits.

Mac app (easiest)

A signed, notarized CCC.app that lives in your menu bar and updates itself. Download the DMG, drag to Applications, done.

Download the DMG

Homebrew

For people who already live in brew. Upgrade later with brew upgrade ccc.

brew tap amirfish1/ccc brew install ccc

Windows

Native PowerShell one-liner, or run the bash line inside WSL2.

irm https://raw.githubusercontent.com/amirfish1/claude-command-center/main/scripts/install.ps1 | iex

From source

Same result, you just clone first. Re-running the installer or a git pull updates CCC.

git clone https://github.com/amirfish1/claude-command-center cd claude-command-center ./scripts/install.sh --from=readme

After install

CCC runs locally at localhost:8090. It lives in ~/.ccc, phones home nowhere, and every agent it shows is one that is actually on your machine.

Fair questions.

Is "curl | bash" safe?

Fair to ask. The installer is a short readable script in the same public repo it installs: read it first at github.com/amirfish1/claude-command-center (scripts/install.sh). It never uses sudo, installs under your home folder only, and every extra component the setup tour adds asks your OK first. Prefer a signed app? Use the DMG above.

Where does everything go?

CCC itself: ~/.ccc/claude-command-center. Its settings and state: ~/.claude/command-center. The free-model router it can install: ~/.ccc/freellmapi. Nothing touches system folders.

What does the free model really cost?

$0. The first stop is a keyless provider that needs no signup. The catch, told to you plainly in the tour: that provider logs prompts to train its models, so keep secrets out of it. You can add a free API key from Google, Groq, Cerebras, or OpenRouter for better quality, still $0. Or point CCC at your paid Claude login whenever you like; it works with both.

How do I update or uninstall?

Update: re-run the same install line, or git pull in the install folder, or brew upgrade ccc. Uninstall: quit CCC, then delete ~/.ccc/claude-command-center. If you installed the background service, run ./run.sh --uninstall-service first.

Something failed. Now what?

The installer prints what it was doing when it stopped, in plain words. Most failures are a missing Xcode Command Line Tools popup on a fresh Mac: run xcode-select --install, wait for it, and run the line again. Still stuck? Open an issue on GitHub and paste the output.
