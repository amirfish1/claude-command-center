# CCC On-call

Phone alerts and optional phone replies inside Claude Code.

```text
/plugin install oncall --marketplace amirfish1/claude-command-center
```

Run `/oncall:setup` to configure your own channel. Wait mode is off by default.
Run `/oncall:wait on` to wait up to three minutes for a phone reply to a closing
question or permission request. `/oncall:wait off` restores fast notifications.

[Setup, supported CLI versions, proof results and limits](https://github.com/amirfish1/claude-command-center/blob/main/docs/oncall-plugin.md).
