The four rules behind these changes

  1. One dominant signal per card. Working/idle gets the eye first; everything else (issue links, engine, cost tier) is quiet metadata below it.
  2. Progressive disclosure. Engineering plumbing (sidecar status, tool names, stale-call detection) still exists — it just lives behind a "Details" toggle instead of on the default surface.
  3. Plain-language names. No "Mode 3." Every control is named for what it does, in words a non-engineer would use, with a one-line description instead of a tooltip you have to hover to find.
  4. Real affordances for real data. If something's meant to be copied (a session ID), it gets a label, legible contrast, and an actual button — not a transparent span you find by accident.
