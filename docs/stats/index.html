Numbers come from our public Cloudflare Worker over a public D1 aggregate query. The raw source IP is never stored; the worker computes SHA-256(utc_date || daily_secret || ip) at the edge so we can count distinct IPs per day without being able to link the same machine across days. Download-click events do not read or store IP or any other request metadata. Stats are cached for one hour in KV; responses allow 5 minutes of HTTP caching.
