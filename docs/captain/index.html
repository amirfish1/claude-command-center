The completion loop

Activity is not the outcome.

Captain is built around the work returning to the initiating agent with enough evidence to trust it.

Turn intent into durable work

02 · Route

Use context before creating more

Reuse the session that already understands the code when it is the right home. Spawn a worker when independence matters.

03 · Prove

Return evidence, not confidence

Resolve with a summary plus commit or no-code proof, and the tests or screenshots the job requires.
