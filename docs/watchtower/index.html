What survives the prompt

Work remains real after the conversation moves on.

WatchTower stores job state outside any one model context and gives workers a consistent protocol for claiming, resolving, and handing off work.

01 · Queue

Durable named work

File one ticket or import a full plan. Dependencies and status remain available to every worker.

02 · Drain

Workers pull the next job

Configured workers drain queues, wake for new work, and expose when a queue is aging or stuck.

03 · Wait

Completion becomes scriptable

wt wait blocks until the queue has no open tickets, then lets a script or initiating agent continue.

Honest engine scope
