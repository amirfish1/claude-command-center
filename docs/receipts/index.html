WatchTower resolutions

An agent saying “done” is not a receipt.

WatchTower closes work with a resolution: what changed, the commit or explicit no-code proof, and the tests, screenshots, or review evidence the job required.

Evidence requirements follow the job. A documentation task and a UI change should not produce the same receipt.

Four parts of a useful resolution

Proof without ceremony.

01 · Summary

State the material change

A bounded explanation of what the worker changed, decided, or discovered.

02 · Artifact

Point to the work

A commit when code changed, or explicit no-code proof when the outcome is research, review, or configuration.

03 · Verification

Name the evidence

Tests, browser checks, screenshots, or review findings selected for the job rather than added mechanically.

04 · Timeline

Preserve the handoff

The initiating agent can see dependencies, interventions, and the final resolution without reconstructing another transcript.

Do not optimize for agents running

Optimize for work returning with proof.
