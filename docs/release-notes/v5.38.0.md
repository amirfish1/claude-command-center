## Show what your agents did. Run them for $0.

v5.38.0 adds a share card for your agent fleet, a five-minute free start on $0 models, and a way to keep working when your Claude limit hits.

### Share your agent fleet

- **One card for everything your agents did.** Throughput → **Share** draws a 1200x630 or 1080x1080 card: an activity heatmap, one headline number (tokens, agent hours, plan used, cache hits, $ saved, or $0 runs), and three small stats.
- **Links unfurl as the card.** Posting to X, LinkedIn, Bluesky, or Threads (or **Copy link**) uploads only the card image and its headline to a hosted card page, so the post shows your card. If the upload fails, CCC shares the repo link and copies the image.
- **Private by design.** The card holds totals only: no prompts, code, file paths, session names, or project names. A pseudonym is optional.

### Start free in 5 minutes

- **A guided first run.** The curl installer and the Mac app open a setup tour on first run that checks your machine, installs what's missing with your OK at each step (Node.js is downloaded and checksum-verified, no admin password), and runs a first real task on a **$0 model**. It ends with the math: what the run would have cost at API prices.
- **$0 Free sessions.** Pick **$0 Free** in the new-session model row and Claude Code, OpenCode, or Aider runs on free models through a local router CCC installs and supervises on loopback. A free spawn that can't reach the router refuses to start instead of billing your plan.
- **Use the router you already have.** CCC detects freellmapi, 9Router/OmniRoute, free-claude-code, Ollama, LM Studio, or a saved OpenRouter key during setup and offers to use it.
- **Pick the best free model.** `/free-models` races every router model through five small coding tasks and pins the winner.
- **Paid-key presets** for GLM, Kimi, DeepSeek, Qwen, and MiniMax, with international and China endpoints.

### Keep going when a limit hits

- **Settings → Session limits** lists every Claude, Codex, and Devin session stopped by a usage limit. Continue them on a free model where supported, or schedule them to resume when the limit resets, spread across reset times.
- **Headroom bars.** The sidebar shows how much of each Claude, Codex, and Kimi plan is left and when it resets.
- **Savings page** (`/savings`): the API-priced value of your agents' work against your plan cost, plus what $0 runs saved.

### Smaller things

- Speak reads replies in a local Kokoro voice first, streaming a sentence at a time; Deepgram is opt-in.
- Run CCC from a locally built wheel with `uvx` or `pipx`.
- Restarting the dashboard or worker on Linux no longer kills running sessions or engine turns (systemd `KillMode=process`; re-run `./run.sh --install-service` to pick it up).
- Opening files on a Linux server host uses `xdg-open` instead of failing.
- Compact view, scrolling, split-pane attach, and the Sonnet 5 model chip behave correctly.

Pop-ups added in this cycle (limit-hit cards, savings milestones, notifications, star ask, router card, Leftover Mode offer) ship turned off; only the first-run setup tour opens on its own.
